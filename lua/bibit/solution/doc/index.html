to_triangle (binary_array)

Converts binary array to triangle table. First row of resulting table has one int element. Each subsequent row has elements quantity bigger by 2.

        ^                              ^
       / \                            / \
      /   \                          /   \
     / 0,1 \                        / 1,1 \
    *-------*      ------->        *-------*
   / \ 0,2 / \                    / \ 2,2 / \
  /   \   /   \                  /   \   /   \
 /-1,2 \ / 1,2 \                / 1,2 \ / 3,2 \
*-------*-------*              *-------*-------*

Parameters:

  • binary_array {int,...}

Returns:

    {{int,...},...} table of tables of int. Inner tables are triangle's rows

to_pyramid_tree (triangle, top_x, top_y, bottom_y)
Function converts triangle table to pyramid table. Each pyramid tree level has 4 children elements:

    ^
   /1\      <-- first row
  *---*
 /2\3/4\    <-- second row
*---*---*

If triangle is inverted (top_y > bottom_y; y axis goes from top to bottom):

*---*---*
 \2/3\4/    <-- second row
  *---*
   \1/      <-- first row
    *

x coordinate: [-(line_num-1); line_num-1], where line_num is y. See coords.svg, divide.svg for explanation

Parameters:

  • triangle {{int,...},...} big triangle table consisted of rows of integer
  • top_x int
  • top_y int >= 1 and <= triangle height
  • bottom_y int can be < top_x so triangle would be inverted

Returns:

    {{int, string or table,...},...}
